## Installation Instructions

1. **Create Files**: In your GitHub repository, create files with the names listed above (e.g., `index.html`, `settings.html`).
2. **Copy & Paste**: Copy the code from each section above into its respective file.
3. **Internal Linking**: The screens are currently designed as standalone views. To link them, you can update the `href` attributes in the navigation components to point to these filenames (e.g., `<a href="settings.html">`).
4. **Deploy**: Go to **Settings > Pages** on GitHub and enable GitHub Pages from the `main` branch to host your app.
